# 蜗牛回声训练室 V1.2.1

[打开训练室](https://47.239.63.61.sslip.io/) · [本地运行与部署](server-java/README.md) · [发布执行记录](deploy/V1.2.1-CUTOVER-REVIEW.md)

Vue 3 + TypeScript 前端、Java 21 + Spring Boot 后端、MySQL 8.4 和私有 S3 兼容录音存储组成同源 HTTPS 全栈应用。发布镜像由 `server-java/Dockerfile` 构建。

## 五种玩法

| 玩法 | 参与方式 |
| --- | --- |
| 双人同步练 | 独立会话通过邀请加入，表达与复述同步推进，可邀请观察者 |
| 双座位自练 | 一人使用两个座位完成表达、复述和逐条标注 |
| 亲子同机练 | 同一设备交替操作，下一轮交换表达与复述身份 |
| 异步留言练 | 表达者分享邀请；复述者依进入时机等待或打开留言 |
| 单人练习 | 玩家始终为复述者，本人录音与素材库原录音进行分析 |

火山录音识别处理实际提交的音频，方舟模型提取原文要点、对照复述并提供分角色建议。模型输出核验引用和结构，降级建议会注明来源。单人练习不会使用预置复述代替本人录音，也不接收前端传入的成绩。

素材库分享需要录音所属座位主动同意。普通练习上传和同意进入素材库分别处理。参与者的访问权限在后端检查，录音通过短期签名播放，文本在数据库中加密。

## 本地运行和验证

按 [Java 部署说明](server-java/README.md) 配置环境、启动 MySQL 与私有对象存储，再运行 Spring Boot。前端使用 Vue；Node.js 用于前端构建及测试工具。

[CI 工作流](.github/workflows/v1.2-verify.yml) 验证类型检查、前端及共享测试、Java/MySQL/对象存储集成、五种玩法浏览器回归和 Linux 发布镜像。真实供应商脚本和用法见 [发布目录](deploy/README.md)。

## 当前身份范围

当前提供昵称体验登录，权限绑定服务器会话。昵称不是找回账号或跨设备访问历史的凭据，退出登录会撤销当前会话。正式账号、OIDC 和面向未成年人的监护权限属于后续独立验收范围。

自动验收使用合成录音。手机真机麦克风权限、不同设备与网络环境还需实际体验核验。
